## 📌 Overview: Fruit & Vegetable Classifier

This project demonstrates how to build and use a **Convolutional Neural Network (CNN)** model to classify images of fruits and vegetables.

👉 Features:
- Uses TensorFlow and Keras for deep learning
- Loads a pre-trained model
- Predicts the class of an image with confidence score
- Includes a web interface using Streamlit for easy demo
- Works locally and can be deployed for free
