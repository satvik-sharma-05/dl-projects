# 🥦 Fruit & Vegetable Image Classification (CNN)

An end-to-end deep learning project that classifies fruits and vegetables
using a **Convolutional Neural Network (CNN)** built from scratch and deployed
using **Streamlit**.

## 🔹 Features
- Classifies 36 types of fruits and vegetables
- CNN trained using TensorFlow/Keras
- Interactive web app using Streamlit
- Image upload and confidence score

## 🔹 Tech Stack
- Python
- TensorFlow / Keras
- CNN
- NumPy
- Streamlit

## 🔹 How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
